# CodeAtlas AI Agents

Project agents are Markdown files with frontmatter and task-specific instructions.

## Available agents

- `codeatlas-implementer` — implement features and bug fixes with focused tests.
- `codeatlas-reviewer` — review changes for correctness, security, adapters, and coverage.

## Session rule

Read root `CLAUDE.md` before using an agent. Agents must preserve unrelated work and must not commit or push unless explicitly requested.
